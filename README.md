# Online Store Sales Analysis using SQL

## Project Overview

This is a beginner-level SQL project based on an online store sales dataset.

The project focuses on analyzing sales data and answering basic business-related questions using SQL queries.

## Objectives

- Analyze customer orders and product sales.
- Find sales patterns across different regions and categories.
- Practice filtering, grouping, sorting, and aggregation.
- Use SQL subqueries to solve analytical questions.

## SQL Concepts Used

- DDL
- DML
- DQL
- SELECT
- WHERE
- GROUP BY
- HAVING
- ORDER BY
- Aggregate Functions
- Subqueries

## Dataset

The dataset contains information about:

- Order ID
- Customer Name
- Product Name
- Category
- Region
- Quantity
- Price
- Order Date
- Payment Method

## Business Questions

This project answers 10 business-related questions using SQL queries, such as:

- Finding orders with higher quantities
- Analyzing sales by region and category
- Finding average and maximum prices
- Finding total sales for each product
- Using subqueries to compare values with overall averages and maximums

## Key Learning

Through this project, I practiced using SQL to transform raw sales data into meaningful information and improve my problem-solving skills.
